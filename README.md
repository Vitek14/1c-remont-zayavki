# Учёт заявок на ремонт оборудования (1С:Предприятие 8.3)

Учебная конфигурация на управляемых формах для учёта заявок на ремонт техники.  
Сотрудники подают заявки, мастера берут их в работу и закрывают. Ведётся история статусов, формируется отчёт по мастерам.

## Как развернуть

### Вариант 1. Загрузить готовую базу (`.dt`)

1. Создайте новую пустую информационную базу в 1С:Предприятие 8.3 (файловый режим).
2. В Конфигураторе выберите **«Администрирование» → «Загрузить информационную базу…»** и укажите файл `1Cv8.dt`.
3. Запустите 1С:Предприятие — база уже содержит тестовых сотрудников, оборудование и заявки.

### Вариант 2. Загрузить конфигурацию из XML

1. Создайте новую пустую информационную базу.
2. В Конфигураторе выберите **«Конфигурация» → «Загрузить конфигурацию из файлов…»** и укажите папку репозитория.
3. Нажмите **F7** (обновить конфигурацию базы данных).
4. Запустите 1С:Предприятие. Тестовые данные нужно ввести вручную (см. раздел «Тестовые данные»).

## Структура метаданных

- **Справочники:** `Сотрудники` (Наименование, Должность), `Оборудование` (Наименование, ИнвентарныйНомер, Владелец — подчинён «Сотрудникам»).
- **Перечисление:** `СтатусыЗаявки` (Новая, ВРаботе, Выполнена, Отклонена).
- **Документ:** `ЗаявкаНаРемонт` (реквизиты: Заявитель, Оборудование, ОписаниеПроблемы, Мастер, Статус, СуммаИтого; табличная часть `Работы`: ОписаниеРаботы, Часы, Стоимость).
- **Регистр сведений:** `СтатусыЗаявок` (периодический, подчинён регистратору; измерение `Заявка`, ресурс `Статус`).
- **Отчёт:** `ЗаявкиПоМастерам` на СКД.

## Реализованное поведение

1. При выборе оборудования в документе заявитель подставляется из владельца оборудования.
2. Нельзя провести заявку со статусом «Выполнена», если табличная часть «Работы» пуста (выводится сообщение).
3. При проведении в регистр `СтатусыЗаявок` пишется запись, только если статус изменился. Повторное проведение без смены статуса новых записей не создаёт.
4. Кнопка «Взять в работу» на форме: статус → «ВРаботе», Мастер = текущий пользователь.
5. Сумма по табличной части (`СуммаИтого`) пересчитывается сразу при изменении строк «Работы».
